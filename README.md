# BlueOak - Loan Management System

A high-performance, minimalist loan tracking and financial management system built with Next.js, React, and Tailwind CSS.

## Project Structure

- **src/app**: Next.js App Router containing dashboard pages, authentication, and API routes.
- **src/components**: Reusable UI components powered by Shadcn/UI and Framer Motion.
- **src/services**: API interaction layer (currently utilizing high-fidelity mock data).
- **src/lib**: Core logic including database configuration, session management, and utility functions.
- **src/types**: TypeScript definitions for domain entities (Loans, Borrowers, etc.).

## Key Features

- **Interactive Ledger**: Clickable rows for deep-dive loan repayment history.
- **Minimalist UI**: Headerless, data-first design optimized for financial clarity.
- **Responsive Dashboard**: Fully adaptive layout for mobile and desktop lending operations.
- **Dark/Light Mode**: Seamless theme switching for comfortable usage in any environment.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Data Tables**: TanStack Table v8
- **Validation**: Zod + React Hook Form
